Building high-performance native desktop software on Windows in 2026 is an
educational adventure.

Here are three key lessons Gaurav Patil learned while engineering Downex:

1. Respect the Platform:
   Windows has its own unique personality—from the way NTFS handles file locks to
   how the Desktop Window Manager (DWM) handles VSync. Trying to fight the OS
   leads to bugs; embracing native Win32 APIs leads to silky-smooth performance.

2. Details Are Everything:
   The difference between "okay" software and "great" software is in the 1%
   details: eliminating that tiny progress bar flicker, ensuring the uninstaller
   is completely silent, and shaving 10 milliseconds off startup time.

3. The User's Attention Is Sacred:
   Every popup, every notification, and every modal steals focus from the human
   being using the computer. The best software is the software you rarely have
   to think about—it just works effortlessly in the background.
