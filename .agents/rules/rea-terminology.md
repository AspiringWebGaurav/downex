# REA Terminology Rule

## 🔬 CRITICAL DEFINITION: REA = Reverse Engineering / Reverse Engineer Anything
Whenever the user writes **"REA"** in all-caps, it **ALWAYS** means:
1. **Reverse Engineering** or **Reverse Engineer Anything** ([`morluto/rea`](https://github.com/morluto/rea), `rea-agents`).
2. Binary reverse-engineering tools, disassemblies, decompilers, PE analysis, network packet tracing, and protocol inspection.
3. Proprietary reference assets (such as `reference/idm/` and disassemblies stored in the project vault).
4. The REA MCP tool suite (`mcp_rea_*` or `rea-agents`).

## 🛑 STRICT PROHIBITION
- **NEVER** interpret all-caps **"REA"** as the React UI library or React framework.
- The React library is always written with standard mixed casing as **React**.
